### Batch Production:
- **Film 15-30 videos in one shoot session.**
- **Group by format type (talking head, whiteboard/paper reveal) to minimize setup changes.**

**Order Scripts:**
1. Talking Head with close-ups
2. Whiteboard/Paper Reveal with animated elements

**Rank Editors:**
- Basic editors handle simpler edits like talking head.
- Advanced editors tackle more complex formats like whiteboard reveals.

---

### Viral Doubling Rule:
When any video goes viral, immediately create reformatted versions in every other format type (talking head to whiteboard/paper reveal) and schedule them for the next 7 days.
